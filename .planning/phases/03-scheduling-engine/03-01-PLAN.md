  3. Change DEFAULT from 'confirmed' to 'pending'
  4. Drop existing exclusion constraint `appointments_no_overlap`

  6. Add a `confirmation_hours_before` integer column to `studios` table (default 24) — stores how many hours before appointment to trigger confirmation (consumed by Phase 5.1/6)
