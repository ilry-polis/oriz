<interfaces>
API endpoints from Plan 02:
```
GET /api/v1/financial/summary?period=day|week|month&date=2026-04-05
  → { data: { total_revenue, avg_ticket, total_appointments, occupancy_rate, period } }

GET /api/v1/financial/breakdown/professionals?date_from=&date_to=
  → { data: [{ professional_id, professional_name, total_amount, percentage }] }

GET /api/v1/financial/breakdown/services?date_from=&date_to=
  → { data: [{ service_id, service_name, total_amount, percentage }] }

GET /api/v1/payments?date_from=&date_to=&method=&professional_id=&cursor=&limit=
  → { data: [{ id, amount, method, discount_amount, client_name, professional_name, service_name, created_at }], meta: { hasMore, cursor } }

GET /api/v1/commissions?professional_id=&status=&period_start=&period_end=&cursor=&limit=
  → { data: [{ id, professional_id, professional_name, amount, professional_amount, studio_amount, card_fee_amount, status, period_start, period_end }], meta }

GET /api/v1/commissions/summary?period_start=&period_end=
  → { data: [{ professional_id, professional_name, total_professional_amount, total_studio_amount, count, status }] }

POST /api/v1/commissions/pay { commission_ids: [...] }
  → 200
```
