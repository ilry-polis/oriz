<interfaces>
API endpoints from Plan 01:
```
GET /api/v1/packages?service_id=&cursor=&limit=
  -> { data: [{ id, service_id, name, total_sessions, price, validity_days, created_at }], meta }

POST /api/v1/packages { service_id, name, total_sessions, price, validity_days }
  -> 201 { data: PackageRow }

PATCH /api/v1/packages/:id { name?, total_sessions?, price?, validity_days? }
  -> 200 { data: PackageRow }

DELETE /api/v1/packages/:id
  -> 204

POST /api/v1/packages/:packageId/subscriptions { client_id }
  -> 201 { data: SubscriptionRow }

GET /api/v1/packages/:packageId/subscriptions?status=&cursor=&limit=
  -> { data: [{ id, package_id, client_id, sessions_total, sessions_used, status, expires_at }], meta }

GET /api/v1/package-subscriptions/active?client_id=&service_id=
  -> { data: SubscriptionRow | null }
```
