       - Add discount section (collapsed by default, expand with "Desconto" button):

         b. Amount field: if %, convert to centavos on the price
         c. Discount reason: TextField with quick-suggestion chips ("Cortesia", "Fidelidade", "Pacote")
         d. Show final amount: original - discount, with strikethrough on original
       - Enforce max_discount_percentage: fetch studio settings, if current user is not owner and discount exceeds limit, show error and disable confirm button
       - Add split payment support:
         a. After selecting first method + amount, show "+ Adicionar metodo" button
         b. Opens second method selector + remaining amount (auto-calculated)
         c. Both entries sent as payments array to complete endpoint

       - When completing an appointment that has packageSubscriptionId:

         d. If lastSession=true: show dialog "Ultima sessao do pacote [name] da [client]" with "Renovar" button (calls createSubscription for same package)

         b. Call POST /appointments/:id/complete with { payments, discount_amount, discount_reason }
