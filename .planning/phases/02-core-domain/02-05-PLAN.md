<!-- API contracts from backend plans -->

Services API:
```
GET  /api/v1/services           → { data: ServiceRow[], meta: { has_more, next_cursor } }
POST /api/v1/services           → { data: ServiceRow }
GET  /api/v1/services/:id       → { data: ServiceRow }
PATCH /api/v1/services/:id      → { data: ServiceRow }
PATCH /api/v1/services/:id/active → { data: ServiceRow }  (body: { is_active: bool })
DELETE /api/v1/services/:id     → 204

ServiceRow: { id, studio_id, category_id, category_name, name, duration_minutes, price, buffer_minutes, is_active, created_at, updated_at }
```

Professionals API:
```
POST /api/v1/professionals      → { data: ProfessionalRow }
GET  /api/v1/professionals      → { data: ProfessionalRow[], meta: { has_more, next_cursor } }
GET  /api/v1/professionals/:id  → { data: ProfessionalRow + service_ids }
PATCH /api/v1/professionals/:id → { data: ProfessionalRow }
DELETE /api/v1/professionals/:id → 204

ProfessionalRow: { id, studio_id, user_id, name, commission_type, commission_value, card_fee_policy, working_hours, is_active, service_count, created_at, updated_at }
```

       - `listServices()` → GET /api/v1/services, parse response.data into List<ServiceModel>
       - `createService(input)` → POST /api/v1/services

       - `deleteService(id)` → DELETE /api/v1/services/:id

    3. **ServiceMgmtProvider** — Riverpod sealed state: Loading/Loaded/Error. Loaded holds Map<String, List<ServiceModel>> (grouped by categoryName). Methods: load, createService (refresh after), updateService (refresh after), toggleActive (optimistic update), deleteService (refresh after).

    4. **ServicesManagementScreen** — Per user decision: "services grouped by category in expandable/collapsible sections". Use ExpansionTile for each category.     5. **ServiceFormScreen** — Reusable for create and edit. Fields: name (TextFormField), category (dropdown from existing categories), duration (number picker or dropdown: 15/30/45/60/90/120 min), price (currency input in R$, stored as centavos), buffer_minutes (dropdown: 0/5/10/15/30 min). Save button submits to API. Validation: name required min 1 char, price > 0, duration > 0.

    6. **ServiceCard** — Widget for service row in list. Shows name, formatted duration ("30 min"), formatted price ("R$ 50,00"). Trailing switch for active/inactive toggle.

    7. **Register routes** — Add /services-management and /services-management/new and /services-management/:id/edit to app_router.dart.
