  <action>
    **Services Management (catalog feel, not storefront):**

    1. ServiceModel: id, name, price, durationMinutes, bufferMinutes, categoryId, categoryName, isActive.

    2. ServiceMgmtRepository: uses ApiClient. Methods: listServices() -> GET /services, createService(data) -> POST /services, updateService(id, data) -> PATCH /services/:id, toggleActive(id, isActive) -> PATCH /services/:id/active, deleteService(id) -> DELETE /services/:id.

    3. ServiceMgmtProvider: Riverpod sealed state (Loading/Loaded/Error). On load, groups services by categoryName into Map<String, List<ServiceModel>>.

    4. ServicesManagementScreen:
       - AppBar title "Servicos", trailing + icon button to add
       - If empty: EmptyStateWidget with "Adicione seu primeiro servico" CTA
       - If loaded: ExpansionTile per category (collapsible sections). Each section header: category name + count. Each row: ServiceCard (name + duration "45 min" + price "R$ 120,00"). Active/inactive visual distinction (inactive rows are dimmed).
       - Tap row -> navigate to /services/:id/edit
       - Pull-to-refresh

    5. ServiceFormScreen: create/edit form. Fields: name (required), category (dropdown from existing categories + "Nova categoria" option), price (R$ formatted), duration (minutes picker or dropdown), buffer_minutes (optional, default 0). Save -> POST or PATCH. Delete button on edit mode (with confirmation).

    **Team Management:**

    6. ProfessionalModel: id, name, commissionType, commissionValue, cardFeePolicy, isActive, serviceIds, userId.

    7. TeamRepository: uses ApiClient. Methods: listProfessionals(), createInvite(data), getProfessionalById(id), updateProfessional(id, data), toggleActive(id, isActive). Also: getInviteInfo(token) and acceptInvite(token, email, password) — these do NOT need auth token.

    8. TeamProvider: Riverpod sealed state for professional list.

    9. TeamManagementScreen:
       - AppBar title "Equipe", trailing + icon button
       - If empty: EmptyStateWidget with "Convide sua primeira profissional" CTA
       - If loaded: List of ProfessionalCard widgets. Each: avatar placeholder + name + commission "15%" + active/inactive badge. Tap -> detail/edit.

    10. ProfessionalFormScreen:
        - Owner fills: name, service checkboxes (fetched from services API), commission % (numeric input), card fee policy (radio: "Estudio absorve" / "Profissional absorve" / "Dividir")
        - On save: calls createInvite endpoint -> receives whatsapp_link
        - Shows success state with "Copiar link" button (copies whatsapp_link to clipboard) and "Compartilhar via WhatsApp" button (launches URL)

    11. InviteAcceptScreen:
        - Receives token from deep link /invite/:token
        - Calls getInviteInfo(token) to show studio name and professional name
        - Form: email + password + confirm password
        - Submit -> acceptInvite(token, email, password)
        - On success: navigates to /agenda (user is now logged in)
        - On error: shows message (expired, already used, email taken)
  </action>
