    **Models:**
    1. ClientModel: id, name, phone, email, birthday, tags (List of String), lastAppointmentAt, createdAt. fromJson/toJson.
    2. AnamnesisModel: id, clientId, serviceCategory, fields (Map of String to dynamic), updatedAt. fromJson/toJson.
    3. AnamnesisField helper: key, label, type (boolean/text/select), options (for select), value.

    **Repository:**
    4. ClientRepository using ApiClient:
       - listClients(cursor?, limit?, search?, tag?): GET /clients with query params
       - getClientById(id): GET /clients/:id
       - createClient(data): POST /clients
       - updateClient(id, data): PATCH /clients/:id
       - updateTags(id, tags): PATCH /clients/:id/tags
       - anonymize(id): DELETE /clients/:id
       - getAnamnesis(clientId, category): GET /clients/:id/anamneses/:category
       - upsertAnamnesis(clientId, category, fields): PUT /clients/:id/anamneses/:category
       - listNotes(clientId, cursor?, limit?): GET /clients/:id/notes
       - createNote(clientId, content): POST /clients/:id/notes
       - listAppointments(clientId, cursor?, limit?): GET /clients/:id/appointments
       - grantConsent(clientId): POST /clients/:id/consent
       - revokeConsent(clientId): DELETE /clients/:id/consent

    **Anamnesis Templates (local defaults):**
    5. Create anamnesis_templates.dart: const map of category to List of AnamnesisField.
       - lash: alergia_cola (boolean), lentes_contato (boolean), lagrima_artificial (boolean), observacoes (text)
       - micropig: gravidez (boolean), anticoagulante (boolean), queloides (boolean), observacoes (text)
       - unhas: alergia_acetona (boolean), fungos (boolean), observacoes (text)
       - estetica: alergias (text), medicamentos (text), observacoes (text)
       - cabelo: alergias (text), tratamentos_quimicos (text), observacoes (text)

    **Providers:**
    6. ClientListProvider: Riverpod sealed state (Loading/Loaded/Error). Supports search debounce (300ms), tag filter, cursor pagination (load more). State includes: clients list, hasMore, nextCursor, activeSearch, activeTag.
    7. ClientDetailProvider: family provider by clientId. Sealed state.

    **Client List Screen:**
    8. ClientListScreen:
       - AppBar title "Clientes", trailing + button to add
       - Search bar at top (TextField with search icon, debounce 300ms)
       - Below search: horizontal row of filter chips (Todos, VIP, Novo, Inativo) using TagChip widget
       - If empty: EmptyStateWidget "Adicione seu primeiro cliente"
       - If loaded: ListView.builder with ClientListItem widgets. Each: CircleAvatar (initials) + name + last visit date ("Ultima visita: 15 mar"). Loading: ClientListItemSkeleton (shimmer placeholders).
       - Infinite scroll: when near bottom, load next page
       - Tap row -> navigate to /clients/:id

    **Client Form Screen:**
    9. ClientFormScreen (create/edit):
       - Fields: nome (required), telefone (required, Brazilian phone mask from Phase 1), email (optional), data de nascimento (optional date picker, with nudge text "Adicione para enviar parabens automatico"), marketing consent checkbox "Aceito receber mensagens de marketing via WhatsApp" (default: unchecked)
       - On save: POST /clients (create) or PATCH /clients/:id (edit)
       - Phone validation: Brazilian format mask, stored as E.164

    **Widgets:**
    10. TagChip: small rounded chip with label + optional color. VIP = gold, Novo = blue, Inativo = gray, custom = default.
    11. ClientListItem: avatar (initials) + name + last visit date + tag chips.
    12. ClientListItemSkeleton: shimmer loading placeholder matching list item layout.

    **Router:**
    13. Add to app_router.dart: /clients/:id -> ClientDetailScreen, /clients/new -> ClientFormScreen, /clients/:id/edit -> ClientFormScreen (edit mode), /clients/:id/anamnesis/:category -> AnamnesisFormScreen.

    **Client Detail Screen:**
    1. Header section: name (large), phone (tappable to call), email, tag chips (VIP is tappable to toggle, auto-tags are read-only with different style).
    2. TabBar with 3 tabs: Historico | Anamnese | Notas
    3. **Historico tab:** Lists appointments from API (GET /clients/:id/appointments). Each: date + time + service name + status chip (completed/cancelled/no-show). If empty: "Nenhum agendamento ainda" centered text. Cursor-based pagination.
    4. **Anamnese tab:** Shows list of categories with anamnesis status. Each row: category name + "Preenchida" or "Pendente" badge. Tap -> AnamnesisFormScreen for that category. If no anamneses: "Nenhuma anamnese preenchida" with CTA to fill first one.
    5. **Notas tab:** Shows notes timeline (reverse chronological). Each: professional name + date + content text. Input field at bottom (like chat) to add new note. Submit creates note via API, appends to list. Notes are immutable — no edit/delete UI.
    6. Action menu (AppBar trailing ...): "Editar cliente" -> /clients/:id/edit, "Excluir cliente" -> confirmation dialog -> anonymize API call (explains: "Os dados pessoais serao anonimizados. O historico de agendamentos sera mantido.").

    **Anamnesis Form Screen:**
    7. Receives clientId + category from route params.
    8. Loads template defaults from local anamnesis_templates.dart, then overlays saved values from API (GET /clients/:id/anamneses/:category).
    9. Renders form fields dynamically based on AnamnesisField type:
       - boolean -> SwitchListTile
       - text -> TextField
       - select -> DropdownButtonFormField
    10. "Adicionar campo" button at bottom -> lets professional add custom field (text type by default).
    11. Save -> PUT /clients/:id/anamneses/:category with all field values.
    12. On success: pop back to client detail.
